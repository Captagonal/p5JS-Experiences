## 🎨 Title  

# P5ball

---

## ✨ Description  

The inspiration for my sketch was obviously pinball machines, and I was actually thinking about wanting to make a little pinball game so when the assignment was put out I took my chance and made a little web based pinball game. You can control the game a few ways, You can click on either side to activate the paddles, or if its touch screen you can use that, lastly if you have a keyboard you can use left and right arrow. You earn points by hitting the bumpers, rolling over the lights (with a bonus for getting them all), and a few for going through the track.

---

## ⚙️ Setup  

Someone should visit the hosted [site](https://captagonal.github.io/p5JS-Experiences/2D%20Interactive/) where they can play the game, otherwise you can download the code and open in vscode and use "Open with live server" to start the game. I use p5.js to run the game and provide all the graphics, and I use Firebase Firestore to provide the database to keep track of scoring.
